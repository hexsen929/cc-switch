# CC Switch v4.0.6 — fork 在线更新修复

修复旧 fork 安装包显示 `4.0.5`，却无法发现 `4.0.5-codex-auth-74` 的问题。旧更新器按 SemVer 把带后缀的版本视为比 `4.0.5` 更旧的预发布版。

本次发布为 `v4.0.6-codex-auth-75`，让 73、74 安装包无需先更换更新器即可发现它。新安装包会记录完整 tag，后续同版本 fork 发行按数字序号比较；相同或较旧版本不会反复提示升级。Windows 安装器和 macOS 构建号保持平台要求的数字格式。

本版本同时包含 74 的 Codex 工具调用桥接修复：保留命名空间、自定义工具和工具搜索类型。需要桥接的供应商仍须单独开启“工具调用桥接”，普通中转维持原有路径。

发布完成后，在“关于”点击“检查更新”即可获取本版本。数据库结构未变化。
