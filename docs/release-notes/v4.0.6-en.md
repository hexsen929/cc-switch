# CC Switch v4.0.6 — fork updater fix

Older fork packages embedded `4.0.5`, so the default SemVer comparison treated `4.0.5-codex-auth-74` as an older prerelease and reported no update.

This release uses `v4.0.6-codex-auth-75` so installed 73 and 74 packages can discover it with their existing updater. New packages embed the full release tag and compare fork revision numbers numerically. Equal or older versions are not offered again. Windows installer versions and macOS build numbers use their required numeric formats.

It also includes release 74's Codex tool bridge fix, preserving namespaces, custom tools, and tool-search types. Enable tool bridging only on providers that need it; ordinary provider routing is unchanged.

After publication, choose Check for Updates on the About page. The database schema is unchanged.
