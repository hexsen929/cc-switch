# CC Switch v4.0.6 — fork のオンライン更新を修正

旧 fork パッケージの内部バージョンは `4.0.5` だったため、標準の SemVer 比較では `4.0.5-codex-auth-74` が古いプレリリースとして扱われ、更新が見つかりませんでした。

今回は `v4.0.6-codex-auth-75` として公開し、73 と 74 に組み込まれた更新機能でも検出できるようにします。新しいパッケージには完全なタグを埋め込み、以降の fork 番号を数値で比較します。同じ版や古い版への更新は提示しません。Windows インストーラーと macOS のビルド番号には対応する数値形式を使用します。

74 の Codex ツール橋渡し修正も含みます。名前空間、カスタムツール、ツール検索の型を保持します。必要なプロバイダーだけでツール橋渡しを有効にしてください。

公開後、「このアプリについて」から更新を確認できます。データベース構造は変更していません。
